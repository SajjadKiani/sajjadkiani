## 👨‍💻 About Me

- 🎓 Computer Science grad, currently **CTO @ Zhama**
- 🌐 Frontend developer at heart who loves **Web3** — I ship full products, frontend to backend
- 🤖 Building **LLM-powered automation**: Telegram bots that summarize channels with OpenRouter / Gemini, and MCP servers that let agents talk directly to exchanges
- 📈 Deep into **algorithmic trading & market-making** — DEX trading APIs, Polymarket bots, order books
- 🔐 Also tinker with networking tools for open, censorship-resistant internet access
- 🌱 Currently exploring the **Model Context Protocol (MCP)** and agentic trading systems
- 📫 Reach me at **[sajadkiyani.ir](https://sajadkiyani.ir)**
